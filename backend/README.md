# backend

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

To build the backend for Bun:

```bash
bun run build
```

The build output is written to `dist/`.

This project was created using `bun init` in bun v1.4.1. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
